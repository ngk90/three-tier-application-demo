# Overview

This is a reference implementation of a three-tier web application built with Next.js, Express, and PostgreSQL. It demonstrates how a modern frontend, REST API, and database communicate in a production-ready architecture. The application is a simple task manager (to-do list) that you can run locally with Docker Compose or deploy to Google Cloud Platform using Terraform.

## What is a three-tier application?

A three-tier architecture separates an application into three logical layers:

1. **Frontend (Presentation)** — User interface and client-side logic
2. **API (Business Logic)** — Server-side processing and data validation
3. **Database (Data)** — Persistent storage and queries

This separation allows each layer to scale independently and be maintained by different teams.

## Quick start

To run the application locally:

```bash
docker compose up --build
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

The Docker Compose setup automatically:
1. Starts a PostgreSQL 17 database
2. Applies database migrations
3. Launches the Express API on port 3001 (internal)
4. Runs the Next.js frontend on port 3000 (accessible to you)
