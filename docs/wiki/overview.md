# Overview

This is a reference implementation of a three-tier web application demonstrating how to build, run, and deploy a modern full-stack system. The project combines a Next.js frontend, an Express REST API, and a PostgreSQL database into a cohesive task management application. It runs locally with Docker Compose and deploys to Google Cloud Platform using Terraform, making it an ideal template for understanding cloud-native architecture patterns.

## What is a Three-Tier Application?

A three-tier architecture separates concerns into three distinct layers:

1. **Presentation Tier** — User interface (Next.js frontend)
2. **Application Tier** — Business logic and API (Express server)
3. **Data Tier** — Persistent storage (PostgreSQL database)

This separation enables independent scaling, easier testing, and clearer responsibility boundaries.

## Technology Stack

| Layer | Technology | Location |
|-------|-----------|----------|
| Frontend | Next.js 16, React 19, Tailwind CSS | `src/web/` |
| API | Express 5, Node.js 22 | `src/api/` |
| Database | PostgreSQL 17 | managed by Docker / Cloud SQL |
| Migrations | node-pg-migrate | `src/db/` |
| Infrastructure | Terraform (GCP) | `src/infrastructure/` |

## Application Overview

The demo implements a simple **task manager** (to-do list) that showcases how the three tiers communicate:

- Users interact with the Next.js frontend in their browser
- The frontend calls REST API endpoints on the Express server
- The API queries and updates data in PostgreSQL
- Database migrations manage schema changes

## Key Features

- **Local Development** — Full stack runs with `docker compose up --build`
- **Cloud Deployment** — Terraform provisions infrastructure on Google Cloud Platform (Cloud Run + Cloud SQL)
- **Database Migrations** — Schema changes managed with node-pg-migrate
- **Containerized** — Each tier has its own Dockerfile for consistency across environments
- **Networking** — Internal service-to-service communication; only the frontend is publicly exposed

## Quick Start

To run the application locally:

```bash
docker compose up --build
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

The stack automatically:
1. Starts PostgreSQL
2. Applies database migrations
3. Launches the Express API (port 3001, internal only)
4. Serves the Next.js frontend (port 3000, accessible on host)
