This is a reference implementation of a three-tier web application built with Next.js, Express, and PostgreSQL. It demonstrates how to structure a modern full-stack application that runs locally with Docker Compose and deploys to Google Cloud Platform. The example application is a simple task manager (to-do list) that showcases communication between all three tiers.

## What is a three-tier application?

A three-tier architecture separates an application into three logical layers:

- **Frontend (Presentation)** — User interface and client-side logic
- **API (Business Logic)** — Server-side application logic and data processing
- **Database (Data)** — Persistent data storage

This separation enables independent scaling, easier testing, and clearer responsibility boundaries.

## Technology stack

| Layer | Technology | Location |
|-------|-----------|----------|
| Frontend | Next.js 16, React 19, Tailwind CSS | `src/web/` |
| API | Express 5, Node.js 22 | `src/api/` |
| Database | PostgreSQL 17 | managed by Docker / Cloud SQL |
| Migrations | node-pg-migrate | `src/db/` |
| Infrastructure | Terraform (GCP) | `src/infrastructure/` |

## Key features

- **Local development** — Start the entire stack with a single `docker compose up --build` command
- **Database migrations** — Automated schema management with node-pg-migrate
- **Cloud deployment** — Infrastructure-as-code with Terraform for Google Cloud Platform
- **Task manager example** — A working to-do list application demonstrating CRUD operations
- **REST API** — Standard HTTP endpoints for task management

## Quick start

### Prerequisites

- [Docker Desktop](https://www.docker.com/products/docker-desktop/) (or Docker Engine + Compose plugin)

### Run locally

```bash
docker compose up --build
```

This starts four services:

1. **postgres** — PostgreSQL 17 database
2. **migrate** — Applies database schema migrations
3. **api** — Express API on port 3001 (internal only)
4. **web** — Next.js frontend on port 3000

Open [http://localhost:3000](http://localhost:3000) in your browser once the stack is running.

### Stop the stack

```bash
# Stop containers (keeps data)
docker compose down

# Stop and delete all data
docker compose down -v
```
