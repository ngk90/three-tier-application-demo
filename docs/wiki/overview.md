# Overview

_Generated by Forge from `main` at `9e9f20c`._

This is a reference implementation of a three-tier web application: a Next.js frontend, an Express REST API, and a PostgreSQL database. It runs locally with Docker Compose and deploys to Google Cloud Platform (Cloud Run + Cloud SQL) via Terraform. The application is a simple task manager that demonstrates how the three tiers communicate with each other.

## What is a three-tier application?

A three-tier architecture separates an application into three logical layers:

- **Presentation tier** — the user interface (Next.js frontend)
- **Application tier** — the business logic (Express API)
- **Data tier** — persistent storage (PostgreSQL database)

This separation enables independent scaling, easier testing, and clearer responsibility boundaries.

## Key features

- **Local development** — Start the entire stack with `docker compose up --build`
- **Database migrations** — Automated schema management with node-pg-migrate
- **Cloud deployment** — Terraform provisions Cloud Run, Cloud SQL, VPC, and IAM on GCP
- **Task manager demo** — A working to-do list application showing CRUD operations across all three tiers

## Quick start

### Local development

```bash
docker compose up --build
```

Open [http://localhost:3000](http://localhost:3000) in your browser. The stack includes:

1. PostgreSQL database (port 5432, internal only)
2. Database migrations (runs once on startup)
3. Express API (port 3001, internal only)
4. Next.js frontend (port 3000, exposed to host)

### Deploy to GCP

```bash
cd src/infrastructure
terraform init
terraform apply -var="project_id=my-project" \
                -var="api_image=gcr.io/my-project/api:latest" \
                -var="web_image=gcr.io/my-project/web:latest"
```
