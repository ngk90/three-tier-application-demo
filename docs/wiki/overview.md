# Overview

_Generated by Forge from `main` at `9e9f20c`._

This project is a reference implementation of a three-tier web application demonstrating modern full-stack development practices. It combines a Next.js frontend, Express REST API, and PostgreSQL database, running locally with Docker Compose and deployable to Google Cloud Platform via Terraform. The application is a simple task manager that showcases how the three tiers communicate and integrate.

## Project Structure

The codebase is organized into four main layers:

| Layer | Technology | Location |
|-------|-----------|----------|
| **Frontend** | Next.js 16, React 19, Tailwind CSS | `src/web/` |
| **API** | Express 5, Node.js 22 | `src/api/` |
| **Database** | PostgreSQL 17 | managed by Docker / Cloud SQL |
| **Migrations** | node-pg-migrate | `src/db/` |
| **Infrastructure** | Terraform (GCP) | `src/infrastructure/` |

## Architecture Overview

The application follows a classic three-tier architecture where the browser communicates with the Next.js frontend, which calls the Express API, which queries the PostgreSQL database:

```
Browser → Web (Next.js :3000) → API (Express :3001) → PostgreSQL
```

## Key Features

- **Local Development**: Full stack runs in Docker Compose with a single command
- **Database Migrations**: Automated schema management using node-pg-migrate
- **Cloud Deployment**: Infrastructure-as-code with Terraform for GCP (Cloud Run + Cloud SQL)
- **Task Management**: Simple to-do list application demonstrating CRUD operations
- **API-First Design**: RESTful endpoints for all data operations

## Quick Start

To run the application locally:

```bash
docker compose up --build
```

This starts four services:
1. **postgres** — PostgreSQL 17 database
2. **migrate** — applies schema migrations automatically
3. **api** — Express API (internal only)
4. **web** — Next.js frontend on http://localhost:3000

## Core API Endpoints

The Express API provides the following endpoints for task management:

| Method | Path | Description |
|--------|------|-------------|
| GET | `/health` | Health check |
| GET | `/tasks` | List all tasks |
| POST | `/tasks` | Create a task |
| PATCH | `/tasks/:id` | Update a task |

## Deployment

The project includes Terraform configuration in `src/infrastructure/` for deploying to Google Cloud Platform. It provisions a VPC network, Cloud SQL PostgreSQL instance, Cloud Run services, and necessary IAM bindings. See the Deployment to GCP page for detailed instructions.
