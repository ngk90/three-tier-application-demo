This is a reference implementation of a three-tier web application that demonstrates how to build, run, and deploy a modern full-stack system. It combines a Next.js frontend, an Express REST API, and a PostgreSQL database—all orchestrated with Docker Compose for local development and Terraform for deployment to Google Cloud Platform.

## What is a three-tier application?

A three-tier architecture separates concerns into three independent layers:

- **Presentation tier** — The user-facing interface (Next.js frontend)
- **Application tier** — Business logic and data access (Express API)
- **Data tier** — Persistent storage (PostgreSQL database)

This separation makes the application easier to develop, test, scale, and maintain.

## The example application

The project implements a simple task manager (to-do list) that demonstrates how the three tiers communicate:

```
Browser → Web (Next.js :3000) → API (Express :3001) → PostgreSQL
```

Users interact with the Next.js frontend in their browser, which calls the Express API to fetch and modify tasks, and the API queries the PostgreSQL database to persist changes.

## Quick start

To run the entire stack locally with Docker Compose:

```bash
docker compose up --build
```

This starts four services:

1. **postgres** — PostgreSQL 17 database
2. **migrate** — applies schema migrations, then exits
3. **api** — Express API on port 3001 (internal only)
4. **web** — Next.js frontend on port 3000 (exposed to host)

Open [http://localhost:3000](http://localhost:3000) in your browser once the services are running.

## Deployment

The project includes Terraform configuration in `src/infrastructure/` to deploy to Google Cloud Platform:

- **Cloud Run** for the API and web frontend (serverless containers)
- **Cloud SQL** for PostgreSQL (managed database)
- **VPC** and networking for secure communication
- **Secret Manager** for database credentials

See the "Deployment to GCP" page for detailed instructions.

## Key features

- **Local development** — Full stack runs in Docker Compose with a single command
- **Database migrations** — Schema changes managed with node-pg-migrate
- **Infrastructure as code** — Terraform provisions all GCP resources
- **Containerized** — Each tier has its own Dockerfile for consistency
- **Production-ready** — Demonstrates best practices for three-tier applications
