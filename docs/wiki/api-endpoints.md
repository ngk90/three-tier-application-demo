# API Endpoints

The application exposes a REST API built with Express that handles task management operations. The API runs on port 3001 and communicates with PostgreSQL to persist data. All endpoints accept and return JSON, and the API is designed to be called by the Next.js frontend layer.

## Task Operations

### List All Tasks

```
GET /tasks
```

Returns an array of all tasks ordered by creation date (oldest first).

**Response:**
```json
[
  {
    "id": 1,
    "title": "Buy groceries",
    "completed": false,
    "created_at": "2024-01-15T10:30:00Z"
  },
  {
    "id": 2,
    "title": "Write documentation",
    "completed": true,
    "created_at": "2024-01-15T11:00:00Z"
  }
]
```

### Create a Task

```
POST /tasks
```

Creates a new task with the provided title.

**Request body:**
```json
{
  "title": "Learn Docker"
}
```

**Response:** `201 Created`
```json
{
  "id": 3,
  "title": "Learn Docker",
  "completed": false,
  "created_at": "2024-01-15T12:00:00Z"
}
```

**Validation:**
- `title` is required and must be a non-empty string
- Returns `400 Bad Request` if validation fails

### Update a Task

```
PATCH /tasks/:id
```

Updates an existing task by ID. You can toggle the `completed` status, rename the task, or both.

**Request body (examples):**
```json
{ "completed": true }
```
or
```json
{ "title": "Updated task name" }
```
or
```json
{ "completed": false, "title": "New title" }
```

**Response:** `200 OK`
```json
{
  "id": 3,
  "title": "Updated task name",
  "completed": true,
  "created_at": "2024-01-15T12:00:00Z"
}
```

**Error responses:**
- `404 Not Found` if the task ID does not exist
- Omitted fields in the request body are left unchanged

## Implementation Details

The API is implemented in `src/api/index.js` and uses:

- **Express 5** for HTTP routing and middleware
- **PostgreSQL** connection pool via `src/api/db.js` for database queries
- **JSON body parsing** via `express.json()` middleware
- **Parameterized queries** to prevent SQL injection

All task queries use the `tasks` table with columns: `id`, `title`, `completed`, and `created_at`.
