# API Endpoints

_Generated by Forge from `main` at `066e1ef`._

The REST API is a Node.js Express server (`src/api/index.js`) that manages a task list stored in PostgreSQL. It provides four endpoints for health checks, listing tasks, creating new tasks, and updating existing tasks. All endpoints communicate with the database through a connection pool (`src/api/db.js`) and return JSON responses.

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | `/health` | Health check |
| GET | `/tasks` | List all tasks |
| POST | `/tasks` | Create a new task |
| PATCH | `/tasks/:id` | Update a task |

## GET /health

Returns the API health status.

**Response (200 OK):**
```json
{ "status": "ok" }
```

## GET /tasks

Retrieves all tasks ordered by creation date.

**Response (200 OK):**
```json
[
  {
    "id": 1,
    "title": "Buy groceries",
    "completed": false,
    "created_at": "2025-01-15T10:30:00Z"
  },
  {
    "id": 2,
    "title": "Write documentation",
    "completed": true,
    "created_at": "2025-01-15T11:00:00Z"
  }
]
```

## POST /tasks

Creates a new task with the provided title.

**Request body:**
```json
{ "title": "Learn Express" }
```

**Response (201 Created):**
```json
{
  "id": 3,
  "title": "Learn Express",
  "completed": false,
  "created_at": "2025-01-15T12:00:00Z"
}
```

**Error responses:**
- **400 Bad Request** — if `title` is missing, not a string, or empty:
  ```json
  { "error": "title is required" }
  ```

## PATCH /tasks/:id

Updates an existing task by ID. You can update the `completed` status, the `title`, or both.

**Request body (examples):**
```json
{ "completed": true }
```
or
```json
{ "title": "Updated task name" }
```
or
```json
{ "completed": false, "title": "New title" }
```

**Response (200 OK):**
```json
{
  "id": 1,
  "title": "Updated task name",
  "completed": true,
  "created_at": "2025-01-15T10:30:00Z"
}
```

**Error responses:**
- **404 Not Found** — if the task ID does not exist:
  ```json
  { "error": "Not found" }
  ```

## Implementation Details

The API is implemented in `src/api/index.js` using Express 5 and Node.js 22. It uses a PostgreSQL connection pool from `src/api/db.js` to execute queries. All endpoints:

- Accept and return JSON
- Validate input (e.g., `title` must be a non-empty string)
- Return appropriate HTTP status codes (201 for creation, 400 for validation errors, 404 for missing resources)
- Trim whitespace from string inputs

The API runs on port 3001 (configurable via the `PORT` environment variable) and connects to PostgreSQL using the `DATABASE_URL` environment variable.
