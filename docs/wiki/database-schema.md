# Database Schema & Migrations

This application uses **node-pg-migrate** to manage PostgreSQL schema changes in a version-controlled, reproducible way. Migrations are applied automatically when the application starts via Docker Compose, and can be run manually for development or production deployments.

## Schema Overview

The database currently contains two tables:

| Table | Purpose | Key Columns |
|-------|---------|-------------|
| `users` | User accounts | `id` (PK), `email` (unique), `created_at` |
| `tasks` | To-do items | `id` (PK), `title`, `completed`, `created_at` |

Both tables use auto-incrementing serial IDs as primary keys and include `created_at` timestamps that default to the current time.

## Migration Files

Each migration includes a `down` function to roll back changes if needed.

## Running Migrations

### Automatic (Docker Compose)

When you run `docker compose up`, the `migrate` service automatically applies all pending migrations before the API starts:

```bash
docker compose up --build
```

The `migrate` service uses `src/db/Dockerfile`, which runs `npx node-pg-migrate up` against the running PostgreSQL instance.

### Manual

To run migrations manually, set the `DATABASE_URL` environment variable and use npm scripts defined in `src/db/package.json`:

```bash
cd src/db
DATABASE_URL=postgres://app:app@localhost:5432/app npm run migrate
DATABASE_URL=postgres://app:app@localhost:5432/app npm run migrate:down
```

## Adding New Migrations

To create a new migration:

1. Generate a timestamped file in `src/db/migrations/`:
   ```bash
   cd src/db
   npx node-pg-migrate create {description}
   ```

2. Implement the `up` and `down` functions using the `pgm` API (see [node-pg-migrate docs](https://salsita.github.io/node-pg-migrate/)):
   ```javascript
   exports.up = (pgm) => {
     pgm.addColumn('tasks', 'priority', { type: 'int', default: 0 });
   };
   
   exports.down = (pgm) => {
     pgm.dropColumn('tasks', 'priority');
   };
   ```

3. Commit the file to version control. The next `docker compose up` will apply it automatically.
