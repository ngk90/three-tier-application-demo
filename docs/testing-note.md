# API Testing Requirements

API contributors should install dependencies and run `npm test` in the `src/api` directory before submitting a pull request. This ensures that all unit tests pass and the code meets the project's quality standards. To do this, navigate to the `src/api` folder, run `npm install` to install dependencies, and then execute `npm test` to run the test suite. Addressing any test failures before submission helps maintain code quality and speeds up the review process.
